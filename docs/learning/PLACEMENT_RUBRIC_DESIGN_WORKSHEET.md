# Placement Rubric Design Worksheet

Status: **DRAFT FOR EDUCATOR REVIEW — NOT ACTIVE IN PLACEMENT OR SCORING**

This worksheet prepares the next assessment-engine milestone. It is not a validated rubric, and no mappings below may be used to generate learner scores, skill findings, stage recommendations or marketing claims until reviewed and approved by qualified English-language educators.

## 1. Review objective

Define what each conversational prompt is intended to elicit, what evidence is valid, what alternative explanations must be considered, and what follow-up is needed before a skill finding can be made.

Reviewers should include educators experienced in English-language teaching and Malayalam-speaking learners. Include varied ages, educational backgrounds, regional speech patterns and code-switching practices in pilot review.

## 2. Provisional prompt inventory

| Prompt ID | Current prompt intent | Candidate evidence to review | Important confounds |
|---|---|---|---|
| intro | Personal introduction and familiar information | Basic vocabulary, comprehensible sentence construction, response relevance | Memorised self-introduction; proper nouns; spelling/transliteration |
| routine | Describe a familiar routine | Present-time expression, sequencing, connected sentences | Topic familiarity; short but accurate answers; tense not required by every response |
| past | Narrate a recent event | Past-time meaning, event sequence, relevant detail | Learner may choose present tense intentionally; culturally unfamiliar weekend concept |
| reason | Explain a goal and its importance | Giving reasons, connecting ideas, vocabulary precision | Prompt comprehension; personal sensitivity; response length alone |
| opinion | Express and support a view | Position, reasons, examples, comparison and cohesion | Topic knowledge, unfamiliarity with online learning, rehearsed opinion |
| scenario | Explain a response to a workplace/team problem | Audience awareness, sequencing, negotiation language and pragmatic appropriateness | Work experience, scenario familiarity, cultural expectations, imaginative confidence |

The clarification prompt is a support action, not an assessment item. It must not itself lower a learner's skill finding or stage.

## 3. Skill definitions for reviewer agreement

For every dimension below, reviewers must write observable indicators, acceptable alternatives, examples at multiple proficiency ranges, and explicit non-evidence.

- **Vocabulary:** range, precision, collocation and contextual appropriateness; do not equate rare words with ability.
- **Grammar:** accuracy and control of structures relevant to the communication task; distinguish occasional slips from recurring patterns.
- **Sentence construction:** clarity, clause relationships, cohesion and ability to connect ideas; do not reward length by itself.
- **Comprehension:** whether the learner understood the prompt and responded to its actual task; record prompt rephrasing and assistance.
- **Fluency:** only from an actual spoken interaction with suitable audio evidence; transcript length cannot measure pauses, pace or continuity.
- **Communication:** whether the intended message is understandable and appropriate to audience/context; accept valid regional and international English variants.
- **Pronunciation:** only from consented audio, with an intelligibility-focused rubric and reviewed Malayalam-accented English examples; accent imitation is not the goal.

## 4. Required analytic rubric format

For each skill and prompt, educators must complete:

| Field | Required content |
|---|---|
| Construct | Precisely defined skill being evaluated |
| Prompt relevance | Why this prompt elicits the construct |
| Observable indicators | Evidence a reviewer can actually hear/read |
| Performance bands | Behaviourally anchored descriptors; no numeric score until calibrated |
| Acceptable variation | Valid grammar, dialect and register alternatives |
| Non-evidence | What must not be inferred from the response |
| Confounds | Topic knowledge, literacy, anxiety, transcription, familiarity, accessibility |
| Follow-up | A short prompt that can clarify ambiguous evidence |
| Sample anchors | Anonymised examples reviewed by multiple educators |
| Disagreement rule | How reviewers resolve or preserve uncertainty |

## 5. Evidence aggregation rules to design

- Require more than one independent response before describing a skill as consistent.
- Keep prompt difficulty and support level attached to each evidence item.
- Record whether the learner asked for translation, rephrasing, hints or extra time.
- Separate response relevance from language accuracy.
- Preserve contradictory evidence rather than averaging it away.
- Mark a dimension as insufficient evidence when it was not tested.
- Do not convert response word count, connector count or surface markers directly into a skill rating.
- Never infer pronunciation, speaking fluency or confidence from typed text or transcript alone.
- Provide human review for low-confidence ASR, ambiguous dialect forms and disputed interpretations.

## 6. Calibration and release gates

Before any automated skill finding is enabled:

1. Recruit a representative, consented pilot sample; document inclusion and exclusion criteria.
2. Have at least two educators independently annotate each calibration response.
3. Measure inter-rater agreement per skill and investigate systematic disagreements.
4. Revise descriptors and examples; repeat calibration.
5. Evaluate performance across Malayalam proficiency, code-switching, age bands and relevant accessibility needs.
6. Test for bias from topic familiarity, education, literacy and speech-recognition quality.
7. Set and publish minimum evidence and uncertainty thresholds.
8. Validate stage recommendations against educator judgement and learner outcomes.
9. Document limitations, version the rubric and establish a review cadence.
10. Keep the automated findings disabled if the release gates are not met.

## 7. Current implementation boundary

The API currently records observable response features and returns a provisional report. This worksheet is documentation only. It does not create active prompt-to-skill mappings, validated descriptors, scores or stage recommendations. A future implementation must consume a separately approved, versioned rubric and retain the rubric version with every assessment.
