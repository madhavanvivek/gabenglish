# Gabroo adaptive practice guidance

## Evidence source

Gabroo may receive a bounded list of curriculum skill keys from the learner's latest exercise attempts. For each lesson/exercise pair, only the latest attempt is counted. A skill is eligible only after at least five distinct exercises have evidence and the latest-attempt accuracy is at or below 50%. The context is limited to three skills and the current learner and learning direction.

This is exercise-performance evidence only. It does not establish a speaking, listening, pronunciation or general language proficiency diagnosis. Free-form conversation text is not silently scored or converted into learner profile evidence.

## Teaching behavior

The teaching policy translates known skill keys into plain practice labels, such as grammar or sentence building, and provides the bounded attempt evidence to the tutor. Gabroo should use it only to select one small, relevant practice opportunity when it naturally fits the conversation.

Gabroo must not quote the learner's percentages or attempt counts, invent specific errors, label the learner, or imply a proficiency diagnosis. It should offer a natural question or one targeted example, and otherwise keep the conversation flowing. If there is no eligible evidence, no skill-specific practice prompt is added.

## Validation

Policy tests cover evidence thresholds, recognized skill keys, bounded context and learner-facing guardrails. Exercise evidence remains separate from self-reported vocabulary recall history and from any future explicitly consented conversational assessment.
